# Moneta — Personal Finance Optimiser

Open `index.html` in any modern browser.

Included:
- Dynamic monthly allocation engine
- Emergency-fund optimisation
- Goal/deadline funding
- Debt avalanche strategy
- Risk-aware investment allocation
- Financial health score
- 12-month wealth trajectory
- What-if stress testing
- Explainable recommendations
- Local browser persistence
- Responsive dashboard
- INR-first design

This is a student-project prototype, not regulated financial advice.
